**SER: Site Equipment Rental**

About the Project

SER is a web-based equipment rental platform developed using Django. It allows customers to browse available equipment and request rentals, while suppliers can manage their equipment listings and rental requests.

Features
👤 Customer and supplier registration and login
🛠️ Add, edit, and delete equipment listings
🔍 Browse and filter available equipment
📩 Send rental requests to suppliers
✅ Approve or reject rental requests
📋 Track rental request status
📞 View supplier contact information after approval

**Technologies Used**

 Frontend: HTML, CSS
 Backend: Python, Django
 Database: SQLite
 
Developed as a Django project.
